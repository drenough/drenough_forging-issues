# DrEnough's Forging - Issue Tracker

This repository is only for tracking issues and bug reports for the DrEnough's Forging Minecraft mod.

## ❗ Important
- The actual mod source code is **private**
- This repo is for **issue tracking only**
- Please check existing issues before creating a new one

## 📝 How to Report an Issue
When creating a new issue, please include:

- **Minecraft version:** (e.g., 1.20.1)
- **Mod version:** (e.g., 1.0.0)
- **What happened:** Describe the issue
- **What you expected to happen:** Describe what should happen
- **Steps to reproduce:** How to make it happen again
- **Crash log / screenshots:** If applicable
